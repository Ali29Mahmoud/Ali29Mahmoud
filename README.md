#  Highlighted Projects

## **Outy**
> A full-featured localized Point-of-Interest (POI) recommendation system and social mobile app.
- **Frontend & Routing:** Flutter mobile application connected to **Spring Boot microservices** via **Apache APISIX API Gateway**.
- **Social & Push Notifications:** Integrated Firebase Cloud Messaging (FCM) for real-time engagement and push notifications.
- **Machine Learning Integration:** Designed and built a personalized POI recommendation engine using **GraphSAGE Graph Neural Networks (GNN)**, powered by **Pinecone Vector Database**.
- **DevOps & Infrastructure:** Orchestrated fully containerized services using **Kubernetes (Kind)**, **Helm**, **Apache Kafka** for event streaming, **Redis** for caching, and **Zipkin** for distributed tracing.

## **BugByte**
> A stackoverflow-like developer Q&A, networking, and community platform.
- **Architecture & Backend:** Engineered with a **React** frontend and a robust **Spring Boot** backend.
- **Databases & Messaging:** Integrated **Elasticsearch** for high-performance search queries, **Redis** for fast session caching/reputation scores, and **Kafka** for event-driven messaging.
- **Key Features:** Implemented JWT authentication, community creation, tag filtering, a voting system, reputation levels, dynamic user feeds, and a real-time notification engine.

## **Fitupia**
> A modern personal fitness tracker for exercise, diet monitoring, and goal tracking.
- Developed a clean-UI application featuring personalized guidance for optimizing health objectives, diet tracking, and active exercise monitoring.
